Jev Calls the Play connecting

Before every NFL snap, Jev, a decision-only AI model that cannot write text, calls run or pass and, on fourth down, go, punt or kick. Each call is made from the latest play visible in the feed, timestamped before the poller sees the outcome, and graded against what actually happened. The baseline is a plain league-tendency table (what coaches usually do in that situation), built from earlier weeks.

Method. Play-by-play comes from ESPN's public feed, polled every ten seconds, which runs some seconds behind the stadium, so a call is made from the latest play the poller has seen, before it sees the outcome, and not always before the real snap. When several plays arrive in one poll only the first is graded and the rest are counted as missed. After each play, the code builds the pre-snap situation for the next play (down, distance, field position, score, clock, last three plays, plus league tendency rates for that situation) and asks Jev three typed questions: pass or run, go/punt/kick on fourth down, and the probability of a first down or touchdown. Model pinned to jev-1.13.0. If a penalty or timeout changes the situation before the snap, the call is voided, not regraded. Scrambles and sacks count as pass plays.

Baseline. Smoothed bucket tables from ESPN play-by-play of the prior weeks: pass rate by down, distance, field position and game situation; fourth-down choice rates by distance and field position. Jev is shown those same rates as part of its input, so the comparison is "tendencies alone" versus "tendencies plus judgment".

Backtest before launch (four held-out games, 540 plays, 37 fourth downs): run/pass accuracy tendency 65.0%, Jev 64.6%, always-pass 60.4%. Fourth-down accuracy tendency 62.2%, Jev 64.9%, always-punt 51.4%. Expect Jev to roughly match the tendency table on run/pass and to be more willing than coaches to go for it.
